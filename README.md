# sango-hero-mod-kit

《三國英豪》（SangoHero，2001，龙爱科技）单机游戏的 Cheat Engine 修改工具包。
包含运行时补丁部署脚本、完整逆向笔记与内存结构文档。

> 仅用于单机游戏的本地学习与研究，请支持正版。

## 功能

| 功能 | 说明 | 开关 |
|---|---|---|
| 全屏攻击 | 玩家攻击判定框强制全场覆盖（含纵深） | F7 |
| 极少受击 | 非攻击状态下判定框被清理，敌人几乎无法命中 | 随全屏攻击 |
| 人物专属攻速 | 攻击动画帧除数置 1（12 个攻击状态 × 100 帧） | 常驻 |
| 双轴 4 倍移速 | 横向 5→20、纵向 4→16（每角色数据字段） | 常驻 |
| 0元购 | 金钱地址锁定 999999 | 常驻 |
| 全局变速 | 帧率上限字段 30/60/120/8（快进/慢动作） | 手动 |

## 快速开始

1. Cheat Engine 附加 `SangoHero.exe`，游戏进入任一关卡
2. 用 CE 执行断点（`sub_469190`，0x469190）抓取本局世界对象地址
   （挥一刀，断点寄存器 ECX/ESI 即世界指针）
3. 打开 `sango_deploy.lua`，把顶部 `WORLD` 改成本局地址
4. 整段粘贴进 CE 的 Lua 引擎执行——全屏攻击/移速自动部署，F7 可开关
5. 金钱锁定：CE 扫描当前金钱数值（dword）得到唯一地址后加冻结，
   或参考 `sango_patches.md` 中的定时器写法

重启游戏后堆地址全部变化，重复上述流程即可。

## 文件

- `sango_deploy.lua` — 一键部署脚本（CE Lua）
- `sango_patches.md` — 逆向笔记：内存结构、补丁点、机制解析、踩坑记录

## 逆向要点（详见 sango_patches.md）

- 玩家实体 `[0x4DC450]`：+0=X、+4=Y、+8=动作状态、+0xC=动画帧
- 判定框注册 `sub_469190`：case0=玩家攻击框（环形缓冲 256 槽，消费端仅扫前 10 槽）
- 伤害结算 `sub_467ED0`：框×框重叠 + 命中备忘闸门（按动画 ID 防连招）
- 动画推进 `sub_4A96D0`：`tick % divisor` 节拍器，除数在动画表 +0x370
- 怪物 AI：类型→函数表 0x4C5234，AI 对象 +96/+100 = 世界坐标
